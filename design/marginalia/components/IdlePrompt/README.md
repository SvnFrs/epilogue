# IdlePrompt

One quiet question for an open thing that has gone untouched: "Untouched for 3 weeks. Put it back on Waiting? Your place is kept."

**Provide** `days`, `onPutBack`, `onKeep`.

- Shown once per quiet stretch (21 days by default, a setting), inside the row or card it is about. Never repeated, never a notification, never acted on by itself; logging anything resets the clock.
- Put back makes it `paused`: it moves to Waiting, sorts first, keeps its bookmark, keymap or steps, and its ribbon tucks in.
