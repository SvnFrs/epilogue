# Field

A sunk well for text: a plain input in `ui-lg`, or a ruled note field in Literata (`multiline`), both 17px so iOS never zooms.

**Provide** `label`, `multiline`, `rows`, `hint`, and any input attributes (`value`, `onChange`, `placeholder`…).

- Placeholders say what goes there in the margin's voice: "A line for the margin…", "Chapter, hour, track, page".
- The 1.5px underline is the field's boundary; it turns quill on focus along with the focus ring.
