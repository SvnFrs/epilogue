# Stepper

The log control: one big number in Literata between a clay minus and a clay plus, with its unit and total underneath.

**Provide** `value`, `total` (optional), `unit` ("chapter", "episode", "tale", "hour"), `onChange`.

- It lives in the log sheet. The number ticks up on change; long lists of presets do not belong here.
- Both buttons are clay: the sheet's *Log chapter 10* is its one lamp.
