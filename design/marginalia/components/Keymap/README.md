# Keymap

A game's controls as a list: action, a dot leader, then clay keycaps. Groups on the full map; pinned binds only inside `LeftOff`.

**Provide** `binds` (`{action, keys, pinned?, group?}`), `pinnedOnly`, `grouped`, `more`.

- `keys` is a string: `+` joins a chord ("Ctrl+S", "D-pad ↓+A"), `or` separates alternatives ("Shift or M4"). Caps pick their own shape: single keys square, words wide, mouse buttons rounded at the top, A/B/X/Y round, shoulders and Start/View as pills.
- Write the action as Tyler thinks of it ("Whistle for horse"), not the game's menu label.
- Pin only what gets forgotten; three or four pins is the right size for the card.
