# Note

A line in the margin: where you were (a chapter, an hour mark, a track, a page) in entry ink, when, and what you thought, in Literata.

**Provide** `where`, `when`, children (text or paragraphs), `half` for an unfinished thought (`aside`, in `ink-soft`). Put notes inside `Margin` (`ink`), which spaces them and moves the where/when into a true left margin once it is 460px wide or more.

- Notes are Tyler's words; never truncate them on an entry page.
- No cards, no borders: the margin is the container.
