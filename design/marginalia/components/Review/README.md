# Review

Long-form writing set like a book: a three-line drop cap in entry ink, indented paragraphs, no gaps, capped at `measure`.

**Provide** `<p>` children, `ink`.

- One per entry. Drafts and fragments are `Note`s.
- The drop cap handles Vietnamese initials (Đ, Ơ, Ư) and uses `initial-letter` where the browser has it.
