# HorizonMark

The groups inside Prologue's Waiting shelf, as a glyph and a word: Unsorted (the inbox), Soon, Someday, with an optional count.

**Provide** `horizon`, `count`.

- There is no Now horizon: what is being worked on is on the Open shelf.
- All three stay `ink-soft`; horizons have no colours of their own.
- Use it as the head of each group on Waiting, and in a task's meta when it appears outside its group (search, capture).
