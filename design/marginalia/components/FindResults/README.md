# FindResults

Find inside one part: titles, people, and lines in notes and reviews, each match marked; every result opens its source.

**Provide** `query`, `titles` (entries), `people` (`{name, count, kinds}`), `lines` (`{text, where, title, when}`), `onOpen(result)`, `onAdd`, `addLabel`, `part`.

- On Media, *Add 'query'* opens Add entry with the query typed in; on Prologue it is *Capture 'query'*. With no results it becomes the empty state.
- Marks are `lamp-wash` with a `lamp` underline under `ink` text.
